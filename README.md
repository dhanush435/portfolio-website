# Portfolio Website

A Netflix-style portfolio website for A E SAI DHANUSH - Full Stack Developer.

## Features

- 🎬 Netflix-inspired design and animations
- 📱 Fully responsive design
- 🎯 Interactive profile selection
- 💼 Professional sections (Skills, Projects, Certificates)
- 📞 Contact information with modern UI
- 🎨 Modern CSS animations and effects

## Technologies Used

- HTML5
- CSS3 (with animations)
- JavaScript (ES6+)
- Express.js (for deployment)

## Sections

- **Home**: Hero section with video background
- **Professional**: Education timeline
- **Skills**: Technical skills organized by category
- **Projects**: Featured projects with filtering
- **Certificates & Achievements**: Professional certifications
- **Hire Me**: Contact information and availability
